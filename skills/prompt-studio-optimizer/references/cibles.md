# Cibles d'exécution et formatage

Consultez ce fichier une fois la cible identifiée, et lisez **uniquement** sa section.

2. **Identifier la Cible d'Exécution**, d'après les termes employés :
   - `[CLI / Terminal]` — *ligne de commande, bash, cron, script, automatiser*.
     Zéro bavardage, scripts idempotents, codes de sortie explicites.
   - `[IDE / Cursor / Copilot]` — *fichiers, composant, refactor, ou un nom de techno
     (React, Next.js, Python, Docker…)*. Chemins relatifs complets, diffs sans ellipses.
   - `[Chatbot Web]` — *expliquer, rédiger, pédagogique, pas à pas*. Points d'arrêt.
   - `[Agent Autonome]` — *agent, autonome, LangChain, tool calling*. UNE boucle d'agent.
   - `[Équipe d'Agents]` — *équipe, plusieurs agents, crew, swarm, superviseur, orchestrer*.
     Plusieurs agents qui se passent le travail : un prompt par rôle, plus l'orchestration.

   > [!tip] Un agent ou une équipe ?
   > La mention d'agents seule donne `Agent Autonome`. Il faut un terme d'équipe
   > (*plusieurs agents*, *crew*, *superviseur*, *orchestrer*) pour basculer sur `Équipe`.

   > [!warning] Un nom de framework en mode Recherche est un **sujet**, pas un runtime
   > « Comparer LangChain et LlamaIndex » est une étude à lire dans un chatbot, pas un
   > agent autonome à construire. En mode Recherche, ne retenez que `Chatbot` ou `CLI`.
